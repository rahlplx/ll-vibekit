# CONTEXT.md — How to Use This Harness

> This file explains ll-vibekit. Project context lives in PROJECT.md.

---

## What ll-vibekit Is

A universal vibe coding harness. Drop it into any project.
Works from day one of a new project or mid-way through an existing one.
Merges patterns from 14 top GitHub repos (all gitingested + analyzed).

## Covered Project Types

- **SaaS web app** (any stack)
- **Mobile app** (React Native, Expo, native Android, native iOS)
- **API / backend** (REST, GraphQL, gRPC — any language)
- **CLI tool**
- **AI/ML project**
- **Static site / marketing**

## How It Adapts to Your Project

1. `/setup` reads your codebase (package.json, go.mod, pyproject.toml, etc.)
2. Detects your stack automatically
3. Generates PROJECT.md with your project's specifics
4. Agents read PROJECT.md — they now know YOUR stack, not a template

## Two-Layer Architecture

```
ll-vibekit/         ← generic harness (never edit these)
  CLAUDE.md         ← universal rules (Karpathy + LL)
  agents/           ← generic specialists
  skills/           ← universal skill library
  hooks/            ← automation triggers
  scripts/          ← utility scripts

your-project/       ← your project
  PROJECT.md        ← YOUR project config (generated by /setup)
  WORKING-CONTEXT.md← session state (updated each session)
  DISCOVERIES.md    ← growing knowledge about your project
  INITIAL.md        ← current feature request
  PRPs/             ← your feature plans
```

## First-Time Setup (new project)

```bash
# Install ll-vibekit
git clone https://github.com/rahlplx/ll-vibekit
cd your-project
bash ll-vibekit/install.sh

# In Claude Code:
/setup new
```

## First-Time Setup (existing project)

```bash
cd your-existing-project
bash ll-vibekit/install.sh

# In Claude Code — auto-discovers your stack:
/setup discover
```
