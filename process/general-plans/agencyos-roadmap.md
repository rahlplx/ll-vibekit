# AgencyOS Product Roadmap

## Phase 1 — Foundation (Sprint 1-2)
Goal: auth + content + HITL pipeline working

- [ ] Auth: passkeys + email/password fallback + JWT
- [ ] HITL engine: LangGraph interrupt() + HITLQueue table
- [ ] E1 Content Expert: PydanticAI + RAG context
- [ ] Content module: caption generation + HITL review
- [ ] SvelteKit dashboard: login + content page + HITL queue
- [ ] SSE real-time: HITL badge counter

Done when: agency logs in, E1 generates a caption, human approves.

## Phase 2 — Core Modules (Sprint 3-5)
Goal: agencies use this daily

- [ ] Social: Facebook + Instagram scheduling
- [ ] GBP: E7 drafts review replies (needs Meta App Review)
- [ ] SEO: E2 keyword research + content briefs
- [ ] Inbox: E6 DM + comment replies
- [ ] Billing: SSLCommerz + bKash
- [ ] CRM: client health scores
- [ ] AI Employees: Mira (social), Raj (SEO)

Done when: 10 beta agencies use daily for 2 weeks.

## Phase 3 — Differentiation (Sprint 6-8)
Goal: features competitors cannot copy

- [ ] A2A: cross-expert delegation + external integrations
- [ ] Visual Workflow Editor: Svelte Flow drag-drop
- [ ] Mobile app: React Native + Expo
- [ ] Analytics: E9 weekly reports
- [ ] Bengali video generation (MoneyPrinterTurbo)
- [ ] Data flywheel: DSPy prompt optimization

Done when: agencies produce videos and reports automatically.
