# iOS Setup — React Native + Expo

## Prerequisites
- macOS (required for iOS builds)
- Xcode 16+
- Apple Developer account ($99/year — see HUMAN-TODO.md)
- CocoaPods: `sudo gem install cocoapods`

## Project Setup (same as Android — shared codebase)
```bash
# Same Expo project as Android
npx expo run:ios
# Or: npx expo start → press 'i' for iOS simulator
```

## Building for App Store
```bash
eas build --platform ios --profile production
# Requires: eas.json + Apple Developer account + provisioning profile
```

## Key Files
```
app.json        — Expo config (bundleIdentifier, version)
eas.json        — EAS Build config
ios/            — Native iOS files (auto-generated by Expo)
```

## iOS-Specific Notes
- Minimum iOS version: 16.0 (covers 97%+ active devices)
- Gestures: Expo Router handles iOS swipe-back gesture
- Passkeys: expo-passkeys supports iOS 16+ Face ID/Touch ID
- Push notifications: APNs certificate via EAS
