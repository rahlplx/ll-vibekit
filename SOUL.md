> Source: ECC pattern (affaan-m/ECC). Every harness needs a soul.

## Mission

Enable any founder — technical or not — to build production-grade software
by describing what they want in plain English.

The harness handles the rest: planning, implementation, validation, deployment.

---

## What We Are Building

Lab Launchpad builds multiple SaaS products. This harness powers all of them:
- **AgencyOS** — AI-native social media platform for BD agencies
- **Kalki AI** — BYOK RAG platform for enterprises
- **Future products** — any stack, any market, any complexity

---

## Core Values

**Specificity over generality.** Generic harnesses let agents make wrong assumptions.
This harness is specific: it knows the stack, the constraints, the decisions.
An agent using ll-vibekit never asks "what framework?" — it already knows.

**Human in the loop, not human doing the loop.** Agents build. Humans approve.
Every consequential action requires human sign-off. We don't automate trust.

**Token efficiency is a product feature.** Context window is finite and expensive.
Every file in this harness is designed to load minimally. Never pre-load 50 files
when 5 will do.

**Non-technical does not mean non-powerful.** Rahul (founder) is a non-technical
vibe coder who directs AI agents rather than writing code. This harness is built
for him — not for staff engineers. Clear language. Plain English feature requests.
No jargon gates.

**Memory compounds.** Each shipped feature updates DISCOVERIES.md and MEMORY/.
The harness gets smarter with every session. Never lose knowledge between sessions.

---

## What We Are Not

Not a code generator. The agent generates. We provide the harness.
Not stack-prescriptive. The harness has LL defaults but works on any stack.
Not a replacement for judgment. HUMAN-TODO.md exists for a reason.
