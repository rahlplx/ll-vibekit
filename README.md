## How It Works

**1. Install** into your project:
```bash
git clone https://github.com/rahlplx/ll-vibekit
cd your-project
bash ll-vibekit/install.sh
```

**2. Discover** your project (or configure manually):
```bash
# In Claude Code:
/setup discover     # auto-detects stack from package.json, go.mod, etc.
/setup new          # guided setup for a brand-new project
```
This generates `PROJECT.md` — the file all agents read to understand YOUR project.

**3. Build** with 3 commands:
```bash
# Describe your feature
nano INITIAL.md

# Plan it
/generate-prp INITIAL.md

# Build it
/execute-prp PRPs/your-feature.md
```

---

## Key Concept: PROJECT.md

Every project gets its own `PROJECT.md`. This is generated by `/setup` and
contains: what the project is, the tech stack, existing modules, locked
decisions, and human-only tasks.

Agents read `PROJECT.md` first, every session. It replaces loading 5 separate
context files. It makes every agent stack-aware for YOUR project specifically.

```
New project:       /setup new      → prompts you → generates PROJECT.md
Existing project:  /setup discover → scans files  → generates PROJECT.md
Mid-sprint:        just edit PROJECT.md "Active Sprint" section
```

## Two-Layer Architecture

```
ll-vibekit/         ← generic harness (never edit)
  CLAUDE.md         ← universal rules (Karpathy 4 rules + token efficiency)
  agents/           ← generic specialists (adapt to your stack via PROJECT.md)
  skills/           ← universal skill library
  hooks/            ← automation triggers
  scripts/          ← utility scripts (discover-project.py, digest-repo.py)

your-project/       ← your project (edit freely)
  PROJECT.md        ← generated by /setup — YOUR stack, YOUR decisions
  WORKING-CONTEXT.md← session state (updated each session)
  DISCOVERIES.md    ← growing knowledge (add as you learn)
  INITIAL.md        ← current feature request
  PRPs/             ← your feature plans
  MEMORY/           ← your project's patterns, mistakes, modules
```

## Token Efficiency

Context window is finite. ll-vibekit is designed to use it wisely.

| What loads | When | Tokens |
|-----------|------|--------|
| CLAUDE.md | Always | ~800 |
| PROJECT.md | Always | ~1,500 |
| WORKING-CONTEXT.md | Always | ~500 |
| **Total base cost** | | **~2,800** |
| MEMORY/patterns.md | When coding | +600 |
| One agent file | When needed | +500 |
| One skill file | When needed | +300 |
| **Worst case total** | | ~5,000 |

Compare to: loading all files at once = 40,000+ tokens wasted.
