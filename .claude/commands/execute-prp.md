# /execute-prp — Execute Product Requirements Prompt
> Source: coleam00/context-engineering-intro

Read the PRP at $ARGUMENTS. Implement exactly as specified.

## Pre-flight (Karpathy)
1. Re-read DECISIONS.md — flag any conflict before starting
2. Re-read "Files NOT in scope" — set as hard boundary
3. State success criteria OUT LOUD before writing any code

## Implementation
Follow the PRP's "Implementation order" exactly.
After each file: verify it compiles/parses before moving on.
Do not proceed if any step fails — stop and ask.

## Validation
For EACH success criterion in the PRP:
- [ ] Test it explicitly
- [ ] Show the result
- [ ] Check it off

## Completion
When ALL criteria checked:
1. Update WORKING-CONTEXT.md with what was done
2. Update DISCOVERIES.md if anything new was learned
3. Say: "PRP executed. All success criteria verified."
