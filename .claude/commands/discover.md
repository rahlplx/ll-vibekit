# /discover

After shipping a feature, update the knowledge base.

1. Read DISCOVERIES.md
2. Append what was learned this session:
   - New patterns discovered
   - Mistakes made and how they were fixed
   - Better approaches found
   - Tool/library behaviours discovered
3. Update memory/patterns.md if a new code pattern was used
4. Update memory/modules.md if a new module was added
5. Update HUMAN-TODO.md if any task was completed

Keep entries short. Date-stamp each entry.
